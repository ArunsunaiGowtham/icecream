1. Getting Started

The template is 100% static - no build tools, no package manager, no server required. Open index.html in any browser to preview, or drop the folder onto any static host (Netlify, Vercel, GitHub Pages, cPanel, S3) to go live.

All assets are bundled locally under assets/. There are zero external requests, so the site works offline and on any server configuration.

3. Customization

Business info

Address, phone, email and opening hours appear in the footer of every page. Edit them once per file (or search-replace across the folder):

  • Address: 123 Dessert Lane, 5th Avenue, New York, NY 10001
  • Phone: +1 (555) 234-8765
  • Email: hello@sugarandscoop.com
  • Hours: Mon-Fri 10am-10pm, Sat-Sun 9am-11pm
Products

Product cards are plain HTML. Each card carries the data attributes that power the cart, wishlist and menu filters:

<div class="product-card" data-product
     data-product-id="p-101"
     data-product-name="Rainbow Sprinkle Cone"
     data-product-price="4.5"
     data-product-img="assets/images/ice-cream/cone-sprinkle.jpg"
     data-category="ice-cream classic">
  <img src="assets/images/ice-cream/cone-sprinkle.jpg" alt="...">
  <button type="button" data-wishlist></button>
  <button type="button" data-add-to-cart></button>
</div>

Duplicate a card and change the text, image, price and data-product-id (keep ids unique per product across the whole site).

4. Colors & Dark Mode

All colors are CSS variables defined at the top of assets/css/style.css. Change them once and the whole site updates:

:root {
  --si-primary: #ff5d8f;   /* pink */
  --si-secondary: #9b5cf6; /* purple */
  --si-accent: #2ec4b6;    /* mint   */
  --si-accent-2: #ffa14f;  /* orange */
}

<html data-bs-theme="light"> controls the theme. The header's data-theme-switch button toggles light/dark and saves the preference in localStorage. Dark-mode overrides live in a body[data-bs-theme="dark"] (handled via the same variable tokens, so most sections adapt automatically). To force a single theme, remove the switch button and set the attribute to your choice.

Typography: Baloo 2 (display headings via .font-display) and Nunito Sans (body). Both are embedded as local woff2 files.

5. Navigation

The header uses Bootstrap's navbar with dropdowns. To mark the current page active, add active to the corresponding .nav-link or .dropdown-item (and to its parent li.nav-item.dropdown toggle if the page lives inside a dropdown, like ice-cream.html under Menu). Every page includes the mobile offcanvas menu, cart drawer, search overlay, privacy/terms modals and toast container - keep these markup blocks intact when copying a page shell.

6. JavaScript Hooks

All behavior is driven by data-* attributes handled in assets/js/main.js - no inline scripts needed. Supported hooks:

AttributePurpose
data-search-open / data-search-closeOpen / close the full-screen search overlay.
data-theme-switchToggles light / dark theme (saved to localStorage).
data-add-to-cartAdds the product (from sibling data-product-* on the card) to the cart.
data-wishlistToggles a product in the wishlist (persisted).
data-cart-count, data-cart-items, data-cart-empty, data-cart-totalCart UI slots in the offcanvas drawer.
data-filter + card data-categoryClient-side filtering (used on menu, ice-cream, blog).
data-menu-search + data-searchableLive text search inside a grid.
.si-pagination (data-target, data-page-size) + card data-paginateClient-side pagination.
data-countdown + .cd-days/.cd-hours/.cd-mins/.cd-secsCountdown to a target datetime (e.g. 2026-09-30T23:59:59).
.stat-num (data-target, data-prefix, data-suffix, data-decimals)Animated number counter.
data-validate + required + data-success-messageForm validation and success feedback.
data-bulk-qty, data-rate, data-bulk-totalBulk order price calculator.
.reveal, .reveal-delay-1/2/3Scroll-reveal animations.
.qty-stepper (.qty-dec / .qty-inc)Quantity steppers on product detail pages.

7. Cart & Wishlist

The cart stores items in localStorage under si_cart. Clicking data-add-to-cart reads the product id/name/price/image from the card's data-product-* attributes, adds it to the basket, updates the data-cart-count badge and re-renders the drawer (data-cart-items), with the empty state in data-cart-empty and running total in data-cart-total. A confirmation toast is shown on add. Wishlist works the same way (key si_wishlist) and toggles the heart icon.

8. Search, Filters & Pagination

The full-screen search overlay submits to menu.html?q=...; menu.html reads the query and pre-filters the grid. On listing pages (menu, ice-cream, blog): filter pills carry data-filter="category-name" and cards carry matching data-category tokens (space-separated). Cards also get data-searchable for the live data-menu-search input, and data-paginate for the .si-pagination wrapper. Filter, search and pagination combine together.

9. Forms

Contact and newsletter forms are demo forms. Wrap the form in data-validate, mark inputs with required (plus type="email" for email), and add data-success-message to the form to show a success note on submit. No backend is connected - hook up your own endpoint by editing the form's action.

10. Countdowns & Counters

Countdowns render four cells with classes .cd-days, .cd-hours, .cd-mins, .cd-secs. Set the deadline with data-countdown="2026-09-30T23:59:59". Counters (.stat-num) animate from 0 to data-target when scrolled into view; customize with data-prefix, data-suffix and data-decimals.

11. Scroll Animations

Add .reveal to any element to fade it up on scroll. Stagger siblings with .reveal-delay-1, .reveal-delay-2 or .reveal-delay-3. The back-to-top button (fixed bottom-right) appears after scrolling, and the header collapses its shadow on scroll.

12. Images & Media

Images live in assets/images/ grouped by category (ice-cream/, sundaes/, waffles/, crepes/, milkshakes/, bakes/, blog/, events/, general/, team/, hero/). Hero sections use inline background-image with a 1600px-wide photo for retina sharpness. To swap a photo, replace the file (keep the name) or update the src / background-image. Alt text should describe the dessert for accessibility.

14. Browser Support

Built with Bootstrap 5 (no jQuery), modern CSS variables and vanilla JavaScript (ES6). Works in the latest Chrome, Edge, Firefox and Safari. The layout is fully responsive from mobile to desktop.

15. RTL Support

The template ships with RTL-aware rules ([dir="rtl"] in style.css uses logical CSS properties and mirrored overrides for the navbar, dropdowns, cards, forms, search overlay and auth pages). To publish an Arabic or Hebrew version:

1. In every page's <head>, replace
     <link rel="stylesheet" href="assets/css/bootstrap.min.css">
   with
     <link rel="stylesheet" href="assets/css/bootstrap.rtl.min.css">

2. Set the document direction and language on the <html> tag:
     <html lang="ar" dir="rtl">

3. Flip the social/back-to-top float styles if needed - the core layout
   (navigation, grid, cards, forms, footer) already mirrors correctly.

Bootstrap handles the global direction; style.css provides the dessert-brand RTL overrides so spacing, icons and dropdowns mirror consistently.
